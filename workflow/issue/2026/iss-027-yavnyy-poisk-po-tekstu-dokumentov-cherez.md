# Явный поиск по тексту документов через slice --search

- Created: 2026-11-22
- Updated: 2026-11-22
- Status: in progress
- Kind: request

## Observation

План реализации — [PLN-005](../../plan/2026/pln-005-yavnyy-poisk-po-tekstu-dokumentov-v.md).

В Lipi 1.3.3 [обычный поиск цели](../../../docs/ru/slice.md#target) может
пропустить раздел, в котором слова вопроса встречаются только в тексте.
В [DSC-003](../../discussion/2026/dsc-003-kak-pereyti-ot-voprosa-k-pervomu.md)
явный поиск по тексту помог найти оба известных ответа. Для вопроса без ответа
он тоже вернул совпадения. Выдержки позволили их отбросить.

На 11 синтетических запросах RU/EN точное сравнение пропустило «копию» и
`reports`. Сравнение первых четырёх букв нашло обе формы, но также связало
«платёж» с «платформа» и `port` с `portal`. Пару `copies` / `copy`
пропустили оба способа.

## How to reproduce or where it occurred

В разделе «Политика очистки» с адресом `docs/storage.md#cleanup` на строке 12
написать «Копия хранится 30 дней». В Lipi 1.3.3 запрос
`lipi slice 'Сколько дней хранится копия?'` даёт промах.

## Acceptance criteria

- При `not-found` для текстового запроса обычный `slice` подсказывает готовую
  команду `lipi slice --search 'Сколько дней хранится копия?'`. Поиск по тексту
  запускается только по явному запросу.
- `--search` ищет слова вопроса в заголовках и тексте доступных документов.
  В примере он возвращает заголовок, адрес `docs/storage.md#cleanup` для
  обычного `slice` и короткую выдержку со словами «Копия хранится 30 дней».
  Рядом с адресом среза показать `файл:строка` для редактора, в примере
  `docs/storage.md:12`. Номер указывает на совпадение в исходном Markdown.
  Путь открывается из каталога запуска, в том числе для страницы соседа.
  Для каждого кандидата адрес среза, выдержка, путь и строка доступны и в JSON.
- Без префикса поиск локальный. Если есть подходящее подключение, подсказать
  готовую команду с тем же вопросом, даже когда локально нашлись кандидаты.
  Например, локальная страница упоминает срок хранения журнала, а нужный
  раздел о копии находится у соседа. В выдаче остаются и локальный кандидат,
  и подсказка `lipi slice --search 'имя::Сколько дней хранится копия?'`.
  Эта команда ищет только в [области чтения выбранного подключения](../../../docs/ru/slice-output.md#repo-search).
  В адресе для обычного среза сохраняется `имя::`.
- Даже единственное совпадение остаётся кандидатом для выбора. Если совпадений
  нет, команда сообщает об этом. Если совпала лишь тема, по выдержке должно
  быть видно, какие слова встретились в документе.
- Чем меньше документов области содержат слово запроса, тем больше его вес.
  Каждый документ учитывается один раз, даже если слово повторено в нём сто раз.
  Для локального запроса считаются только местные документы, для `имя::` —
  только документы в области чтения выбранного подключения.
- Поиск обходится без списков служебных слов. Если «что» и «если» встречаются
  на многих страницах, а `API` — лишь на одной, запрос «что если API недоступен»
  ставит страницу с `API` выше страниц, где совпали только «что» и «если».
  Тот же критерий действует для `what if the API is unavailable`.
- Запросы `НДС` и `API` находят эти слова независимо от регистра. Слово,
  встречающееся во всех документах области, сохраняет положительный вес.
  Если в области одна страница с `API`, запрос `api` возвращает её с кодом 0.
- При прочих равных точное совпадение со словом запроса стоит выше совпадения
  по началу того же слова. Например, для запроса `reports` страница с `reports`
  стоит выше такой же страницы с `report`.
- Запрос «Как долго хранят копию?» находит фразу «Копия хранится 30 дней»,
  а `reports` находит слово `report`. Если единственное сходство с запросом
  «платёж» — слово «платформа», список кандидатов пуст. То же для пары
  `port` и `portal`.
- Для запроса «срок хранения копии» раздел со всеми тремя словами в одном
  абзаце идёт выше страницы, где есть только слово «срок».
- Явный `slice --search` возвращает код 0, если выдал хотя бы одного
  кандидата, и 1, если совпадений нет. Код 0 не подтверждает ответ на вопрос.
