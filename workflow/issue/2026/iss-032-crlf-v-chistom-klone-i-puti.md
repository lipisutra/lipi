# CRLF в чистом клоне и пути подключений Windows

- Created: 2026-11-27
- Updated: 2026-11-27
- Status: in progress
- Kind: bug

## Observation

В Lipi 1.4.2 чистый клон с CRLF даёт V3 на правилах и W7 на указателе. На Windows `repos.path` принимает путь от корня диска, хотя подключение должно быть задано относительно проекта.

## Воспроизведение

- Выполнить `lipi init --ci github`, закоммитить проект и клонировать его с `git clone -c core.autocrlf=true`. Выполнить `lipi check` и `lipi init --dry-run`.
- На Windows задать `repos.lib.path` равным `/absolute` и включить чтение `docs`. Выполнить `lipi check`.

## Критерии приёмки 1.4.3

- При LF и CRLF чистая копия проходит проверку, повторное применение правил не предлагает изменений. Новые отпечатки едины для обеих платформ. Прежние отпечатки Windows распознаются без ручной правки lock. Изменение текста правила даёт V3. Указатель с чужим содержимым защищён, откат сохраняет исходные байты.
- Путь с корнем, префиксом диска или UNC даёт C1 на каждой системе. Подключение через `../neighbor` работает. Обе гарантии обязательны в CI на Windows 3.9 и 3.x.
