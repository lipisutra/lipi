# Восстановить обязательный полный прогон на Windows

- Created: 2026-11-27
- Updated: 2026-11-28
- Status: open
- Kind: bug

## Observation

В [CI тега v1.4.2](https://github.com/lipisutra/lipi/actions/runs/46048297483) полный набор на Windows дал 101 падение и 59 ошибок выполнения на Python 3.9, 109 падений и 44 ошибки выполнения на 3.x. Среди причин — окончания строк, кодировка, недопустимые имена файлов и запуск дочерних процессов.

## Порядок восстановления

Для [ISS-032](iss-032-crlf-v-chistom-klone-i-puti.md) обе платформенные проверки блокируют выпуск. Полные наборы Windows запускаются вместе с остальной матрицей при отправке тега выпуска `vX.Y.Z` и при ручном запуске. До устранения падений их результат приводится в сводке для справки.

## Критерий закрытия

Оба полных набора на Windows проходят в GitHub Actions. Удалены временные допуски в workflow и оговорка в порядке выпуска. Падение любого из этих наборов делает полный прогон неуспешным на теге выпуска и при ручном запуске. При отправке ветки, переносе `v1` и при pull request выполняются быстрые проверки.
