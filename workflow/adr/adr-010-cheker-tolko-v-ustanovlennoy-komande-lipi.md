# Чекер только в установленной команде lipi, в проекте нет кода lipi

- Created: 2026-11-16
- Updated: 2026-11-16
- Status: accepted

## Контекст

Проверка нужна локально, в pre-commit и в CI. Копия программы в каждом
проекте увеличила бы объём его изменений и потребовала бы отдельного
обновления каждой копии.

## Decision

- Проект хранит настройки, правила, состояние и, если подключён, шаблон CI.
  Код проверки находится в установленном пакете. Локальные вызовы,
  pre-commit и CI используют `lipi check`.
- `lipi.lock` хранит версию развёртывания. Разные мажорные линии дают
  ошибку V1. Если старше только проект в рамках той же линии, V1 предлагает
  обновить программу и даёт предупреждение.
- Внутри одной мажорной линии новые проверки выходят предупреждениями.
  Повысить уровень до ошибки можно при смене линии. Смысл существующих
  кодов не ужесточается.
- CI устанавливает команду через pipx по тегу мажорной линии
  `git+https://github.com/lipisutra/lipi@vN`. Тег указывает на её последний
  выпуск, например `v1` для линии 1.x.
- Для пакета требуется Python 3.9 или новее.

## Альтернативы

- Копия чекера усложняет обновление и добавляет служебный код в проект.
- Фиксация точной версии в шаблоне CI требует отдельно обновлять его при
  каждом выпуске, чтобы он совпадал с локальной проверкой.

## Последствия

За обновление пакета отвечает pipx, за применение правил —
[`lipi init`](adr-014-edinaya-komanda-init-primenyaet-ustanovlennyy-lipi.md).
Правила доступны в проекте даже на машинах без установленной команды.
