# Базовая линия для существующего долга

- Created: 2026-11-15
- Updated: 2026-11-15
- Status: accepted

## Контекст

При подключении существующего проекта ошибки в его документации уже
накопились. Если ради них ослабить правила, такие же ошибки смогут
появляться и в новом тексте.

## Decision

- Существующие ошибки фиксируются в `.agents/lipi/baseline.json`. Проверка
  падает только на ошибках сверх базовой линии.
- Запись: код, файл, устойчивая суть находки (`subject`: цель ссылки,
  якорь, имя поля) и число повторов. Ни номера строк, ни текст сообщения в
  линию не входят, поэтому её не ломают ни правка выше по файлу, ни
  изменившиеся числа в сообщении, ни новая формулировка.
- В линию попадают только ошибки, не предупреждения, и не ошибки настроек
  (C1): с неверными настройками проверке нельзя доверять.
- `lipi baseline` создаёт или перезаписывает линию; `lipi baseline --prune`
  только убирает исправленное и никогда не добавляет.
- Проверка сообщает, сколько ошибок в линии и сколько уже исправлено.
- При первом развёртывании `lipi init` создаёт отсутствующую линию.
  Повторное применение правил сохраняет линию и зафиксированный в ней долг.

## Альтернативы

- Ослабленные настройки — отвергнуто по причинам выше.
- Комментарии-исключения в документах. Отвергнуто: они разбросаны по
  проекту, их не видно целиком и они не уменьшаются сами.

## Последствия

- Правила действуют в полную силу с первого дня и для старого проекта.
- Долг виден одним файлом под git; его рост виден в diff как явное
  действие.
