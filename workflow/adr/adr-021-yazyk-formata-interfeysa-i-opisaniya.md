# Язык формата, интерфейса и описания

- Created: 2026-11-19
- Updated: 2026-11-19
- Status: accepted

## Контекст

Каждый проект должен вести документацию на удобном ему языке. Сейчас lipi
целиком русский: служебные строки рабочих документов, сообщения, правила,
заготовки и описание самого lipi. Служебные строки — синтаксис, который
читает чекер, поэтому англоязычный проект вынужден писать их по-русски.

## Decision

### Три слоя

| Слой | Язык |
| --- | --- |
| формат: шапки, значения статусов и видов, обязательные разделы, коды в JSON | английский, навсегда |
| интерфейс: сообщения, заготовки при создании | английский по умолчанию, другие — опцией |
| содержимое документов проекта | любой, выбор проекта |

### Формат

- Шапка: `Created`, `Updated`, `Status`, `Kind`, `Result`, `Closed`.
  Статусы и виды — английские слова (`open`, `in progress`, `closed`,
  `accepted`, `bug`, `request`…), обязательные разделы — английские
  заголовки. Точный словарь — в описании рабочих материалов.
- Коды в JSON — те же английские значения; от языка интерфейса JSON не
  зависит.
- Формат не переводится и не настраивается.

### Интерфейс

- Управляемые правила в `.agents/lipi/` и управляемый шаблон CI всегда на английском. Язык интерфейса определяет вывод команд и язык заготовок при их создании.
- Тексты интерфейса вынесены из кода: каталог сообщений
  `locale/<язык>/messages.json`, термины с определениями в `terms.json`
  и комплект `templates/` рядом с ними.
  Английский — основа, русский — первая дополнительная редакция.
- Язык выбирает человек командой `lipi lang <язык>`; выбор хранится в
  личном конфиге `~/.config/lipi/config.json` и действует во всех проектах
  на машине. `lipi lang` без аргумента показывает текущий. Не задан —
  английский. Других способов выбора нет; проект на язык интерфейса не
  влияет.
- Чего нет на выбранном языке — берётся английское: сообщение, термин или файл
  шаблона.
- Каждый перевод хранит отпечаток английского исходника. Тест выводит
  отчёт: непереведённые ключи и переводы, чей исходник изменился. Отчёт,
  не ошибка.
- Доступные языки определяются по наличию папок языков: новый язык добавляется
  переводом, без изменения кода. Неизвестный язык в `lipi lang` — ошибка
  со списком доступных.

### Описание lipi

- Редакции на равных: `docs/en/` и `docs/ru/`; основная — по настройке
  `languages`, проверки L1–L3 следят за парами страниц и якорей.
- Корневые `README.md` и `SETUP.md` — английские: витрина репозитория и
  адрес, который печатает программа; они ссылаются на обе редакции.

## Альтернативы

- Формат на языке проекта. Отвергнуто: синтаксис с двумя словарями без
  пользы; технические ключи понятны на английском всем.
- Основная редакция в `docs/`, остальные во вложенных папках. Отвергнуто:
  языки неравноправны, смена основного — перенос.
- Выбор языка флагом, переменной окружения или локалью системы.
  Отвергнуто: лишние способы; одна команда и один конфиг.
- Конфиг языка внутри установки. Отвергнуто: стирается обновлением.

## Последствия

- Переводы сообщений, терминов и проектных заготовок сверяются с английскими исходниками. У коллег с разными личными настройками управляемые файлы и их отпечатки в lock совпадают.
- Работа идёт до первого публичного выпуска; промежуточных выпусков нет,
  в конце история сводится в один первый коммит `lipi 1.0.0`.
