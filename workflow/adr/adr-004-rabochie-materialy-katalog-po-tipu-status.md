# Рабочие материалы: каталог по типу, статус в шапке, сводки собираются

- Created: 2026-11-15
- Updated: 2026-11-15
- Status: accepted

## Контекст

В существующих проектах планы переезжают между каталогами статусов
(`current/`, `backlog/`, `completed/`), статус пересказывается в
мастер-плане, README и журнале, а журнал и мастер-план разрастаются до
десятков килобайт и расходятся с документами.

## Decision

- Каталог задаёт тип документа: `plan/`, `issue/`, `discussion/`, `adr/`,
  `audit/`. Документ не переезжает при смене статуса.
- Статус записан только в шапке документа, одним значением из списка.
- Указатель `INDEX.md`, списки и журнал собираются из шапок документов.
  Годовые страницы журнала определяет дата закрытия по
  [ADR-020](adr-020-rabochie-dokumenty-po-godam-sozdaniya.md).
- Мастер-план содержит только предстоящее; завершённая работа в нём —
  ошибка.

## Альтернативы

- Каталоги по статусам. Отвергнуто: каждый перенос ломает ссылки, статус
  дублируется каталогом и шапкой.
- Журнал, который ведут руками. Отвергнуто: он повторяет итоги планов и
  расходится с ними.

## Последствия

- Ссылки на рабочие документы стабильны.
- Чтобы указатель был верен, статус в шапке обязан обновляться; отставание
  ловит аудит (A5).
