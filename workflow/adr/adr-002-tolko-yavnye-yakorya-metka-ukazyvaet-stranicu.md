# Только явные якоря, метка указывает страницу

- Created: 2026-11-15
- Updated: 2026-11-16
- Status: accepted

## Контекст

Одинаковые имена разделов встречаются на разных страницах. Метка
должна определять цель однозначно, а ссылка — переживать правку текста
заголовка.

## Decision

- Для ссылок используются явные якоря `<a id="…"></a>`.
- Якорь уникален в пределах страницы.
- Метка имеет одну форму: `@trace путь/страница.md#якорь`, путь от корня
  проекта; несколько целей — через запятую.
- В графе структуры id якоря — `путь/страница.md#якорь`.

Связь с якорем у `covers` в справке приложения — той же формы: страница
называет объясняемый раздел описания системы полным путём,
`<!-- covers: путь/страница.md#якорь -->` (путь от корня проекта). Одна
форма связи с якорем у меток и у `covers`; голое имя якоря не принимается.

## Альтернативы

- Короткая форма метки при уникальном якоре и полная при неоднозначном.
  Отвергнуто: две формы одной вещи; добавление одноимённого якоря на другой
  странице ломало бы метку в чужом месте.
- Глобальная уникальность только для якорей с метками. Отвергнуто: метка в
  коде внезапно ломала бы описание.
- Ссылки на заголовки как второй режим. Отвергнуто: ссылка ломается при
  правке заголовка — ради этого явные якоря и введены.

## Последствия

- Метка длиннее, но однозначна и читается как ссылка.
- Существующие проекты со ссылками на заголовки подключаются через
  базовую линию ([ADR-003](adr-003-bazovaya-liniya-dlya-suschestvuyuschego-dolga.md)).

## Уточнение уровней проверки

По [ADR-012](adr-012-urovni-proverok-nastraivayutsya-v-proekte.md) ссылка на заголовок без явного якоря — отдельный код D7, по
умолчанию ошибка; проект может отключить его (`"codes": {"D7": "off"}`).
Метки `@trace` и `covers` требуют явный якорь всегда.

[ADR-013](adr-013-celi-svyazey-status-celi-i-kontrakt.md) задаёт полный
набор целей связей, включая номера документов.
