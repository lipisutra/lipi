# Файлы lipi и файлы проекта разделены по владельцу

- Created: 2026-11-15
- Updated: 2026-11-15
- Status: accepted

## Контекст

При подключении lipi в проекте могут уже быть правила и рабочие материалы.
Файлы, которые обновляет инструмент, должны иметь явного владельца,
чтобы проект мог сохранять и проверять собственные изменения.

## Decision

| Класс | Файлы | Кто ими управляет |
| --- | --- | --- |
| Правила и CI | Правила в `.agents/lipi/` и шаблон CI при подключении | `lipi init` применяет шаблоны целиком |
| Состояние | `lipi.lock`, `baseline.json`, `reviews.json` в `.agents/lipi/` | Соответствующие команды lipi |
| Заготовки проекта | `AGENTS.md`, страницы в каталогах описания и рабочих материалов | lipi создаёт недостающее при первом развёртывании без настроек, дальше ими управляет проект |
| Файлы проекта | Собственные правила, замечания в `.agents/lipi-feedback/` и рабочие документы | Исполнитель проекта или команды по его просьбе |

- `AGENTS.md` содержит ссылку на `.agents/lipi/README.md`. Новая заготовка
  содержит ссылку сразу. В существующий файл её добавляет проект.
- В lock-файле находятся отпечатки управляемых шаблонов. V2 проверяет
  ссылку в `AGENTS.md`, V3 — состояние файлов lipi.
- Трение с правилами оформляется замечанием к lipi. Изменения проекта
  можно записать в его собственных файлах.

## Альтернативы

Общие файлы с маркерами или слиянием версий шаблона потребовали бы
распознавать правки двух владельцев внутри одной страницы.

## Последствия

Пакет поставляет текущие шаблоны. Установленная команда применяет их
по [ADR-014](adr-014-edinaya-komanda-init-primenyaet-ustanovlennyy-lipi.md).
