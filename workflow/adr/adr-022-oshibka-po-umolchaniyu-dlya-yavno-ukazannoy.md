# Ошибка по умолчанию для явно указанной роли

- Created: 2026-11-21
- Updated: 2026-11-21
- Status: accepted
- Refines: [ADR-010](adr-010-cheker-tolko-v-ustanovlennoy-komande-lipi.md)

## Context

В пределах одной мажорной линии новые проверки по умолчанию выдают
предупреждения. Так обновление lipi само по себе не останавливает проверку
проекта. Автор явно запрашивает проверку роли, когда добавляет к метке
атрибут `role=…`.

## Decision

В линии 1.x для [T5](../../docs/ru/codes.md#t5) установлен уровень
`error` по умолчанию. Он применяется при неверном значении явно указанной
роли или при использовании роли там, где она недопустима. Например,
`role=consumes,produce` даёт ошибку на значении `produce`.

## Consequences

Проект может выбрать уровень `error`, `warning` или `off` через `codes.T5`.
Проверка выпуска учитывает это исключение только для T5 в линии 1.x.
