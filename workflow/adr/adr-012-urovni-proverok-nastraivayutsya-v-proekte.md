# Уровни проверок настраиваются в проекте

- Created: 2026-11-16
- Updated: 2026-11-16
- Status: accepted

## Контекст

Проект выбирает, блокируют ли проверки коммит
([ADR-011](adr-011-strogost-vybor-proekta-klyuch-enforce-po.md)).
Отдельное решение нужно для уровня каждой проверки. Например, проект может
относиться к ссылкам на заголовки мягче, чем к ссылкам на отсутствующие
страницы, а обновление указателя может выполняться автоматически.

## Decision

- Ключ `codes` в `lipi.json`: код проверки → `"error"`, `"warning"` или
  `"off"`. Без ключа действуют уровни по умолчанию из таблицы кодов чекера
  ([справочник](../../docs/ru/codes.md)). Настраивать их при развёртывании
  необязательно.
- Не настраиваются: C1 (неверные настройки) и V1 при несовместимой первой
  цифре — с ними отчёту нельзя доверять. Неизвестный код или уровень в
  `codes` — C1.
- Уровень проекта действует везде: в отчёте, в коде возврата `lipi check`,
  в хуке и CI при `"enforce": true`. Базовая линия хранит только ошибки;
  записи для кодов, понижённых до `warning` или `off`, не учитываются, и
  `lipi baseline --prune` их убирает.
- D7 отмечает ссылку на заголовок без явного якоря. D1 отмечает ссылку
  на отсутствующую цель. По умолчанию D7 —
  ошибка; `"D7": "off"` разрешает ссылки на заголовки. Метки `@trace` и
  `covers` требуют явный якорь всегда: без стабильного имени они не
  работают, это не настройка.
- Указатель рабочих материалов пересобирается сам: локальный `lipi check`
  без `--staged` и `--diff`, вне CI (не задана переменная окружения `CI`)
  и не в формате `github`, найдя устаревшие указатели, пересобирает их и
  сообщает об этом. В остальных случаях проверка ничего не пишет и выдаёт
  W7. Указатель — производный файл: его пересборка не принимает решений за
  разработчика.
- Дисциплина выпусков ([ADR-010](adr-010-cheker-tolko-v-ustanovlennoy-komande-lipi.md)) относится к уровням по умолчанию; уровни
  проекта она не трогает.

## Альтернативы

- Отдельные ключи под каждое пожелание (`anchors`, `index`). Отвергнуто:
  ключ на каждую проверку; общий механизм покрывает и будущие.
- Указатель только по команде `lipi index`. Отвергнуто: устаревание
  указателя — частое трение без пользы.

## Последствия

- Проект меняет уровень проверки одной строкой в `codes`.
- [ADR-002](adr-002-tolko-yavnye-yakorya-metka-ukazyvaet-stranicu.md) уточняется: явные якоря для ссылок — уровень по умолчанию, а не
  обязательное требование.
- Пересборка касается только [комплекта указателей](../../docs/ru/workflow.md#files).
