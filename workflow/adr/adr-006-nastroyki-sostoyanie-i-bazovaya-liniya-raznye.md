# Настройки, состояние и базовая линия — разные файлы

- Created: 2026-11-15
- Updated: 2026-11-15
- Status: accepted

## Контекст

Настройки меняет человек, а сведения о развёрнутых правилах и долге
записывают команды. Эти файлы меняются по разным причинам и с разной
частотой.

## Decision

| Файл | Кто пишет | Что внутри |
| --- | --- | --- |
| `lipi.json` | человек | только настройки |
| `.agents/lipi/lipi.lock` | `lipi init` | версия lipi, отпечатки файлов, созданных из шаблонов |
| `.agents/lipi/baseline.json` | `lipi baseline` | базовая линия |

- Все три файла коммитятся. Пути — по [ADR-009](adr-009-fayly-lipi-i-fayly-proekta-razdeleny.md).
- Неизвестный ключ в `lipi.json` даёт ошибку настроек C1.
- Формат lock-файла и базовой линии — JSON с сортированными ключами, чтобы
  diff был стабильным.

## Альтернативы

- Всё в `lipi.json`. Отвергнуто: машинная запись перетирает ручное
  форматирование и мешает ревью настроек.
- Базовая линия внутри lock-файла. Отвергнуто: она меняется по действиям
  человека и часто, lock — только при обновлении lipi.

## Последствия

- Ревью настроек не смешивается с машинными изменениями.
- Отметки просмотра хранятся отдельно по [ADR-019](adr-019-otmetki-prosmotra-ustarevaniya-po-sostoyaniyu-svyazannyh/adr-019-readme.md).
