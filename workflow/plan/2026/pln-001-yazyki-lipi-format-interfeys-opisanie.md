# Языки lipi: формат, интерфейс, описание

- Created: 2026-11-19
- Updated: 2026-11-19
- Status: completed
- Closed: 2026-11-19
- Result: Для lipi 1.0.0 подготовлены единый английский формат и две языковые редакции интерфейса и документации, английские тексты приняты пользователем.

## Purpose <a id="why"></a>

Реализовать [ADR-021](../../adr/adr-021-yazyk-formata-interfeysa-i-opisaniya.md): формат на английском навсегда,
интерфейс на английском с русским опцией, описание lipi в двух редакциях.

## Подход <a id="approach"></a>

Этапы по коммиту на этап, без промежуточных выпусков, тегов и записей
CHANGELOG. Везде, где можно, — массовые замены скриптом по словарю и
пакетный перевод; руками — просмотр диффа. Комментарии и docstring в коде
не переводятся: это не интерфейс.

Для З0–З1 согласована рабочая таблица замен «русский → английский».
Раздел «формат» использован для разового перевода. С З2 формат определяют
константы программы. Термины для З2 и З3 хранятся в языковых каталогах:
[английские термины и определения](../../../src/lipi/locale/en/terms.json)
и [русский перевод](../../../src/lipi/locale/ru/terms.json).

**Контрольные точки — ровно три:** полный набор после З1; полный набор на
обоих языках после З2; чистая установка из опубликованного тега (З4).
Между ними — адресные тесты затронутых модулей и команд.

## Шаги <a id="steps"></a>

### З0. Словарь

- Файл словаря с двумя разделами (формат и термины), составленный по
  нынешним константам формата и устойчивым терминам описания.
- Вычитка пользователем; до неё массовые замены и перевод не начинаются.

**Готово:** словарь согласован пользователем.

2026-11-19: словарь согласован. В нём 31 значение формата;
статус плана на приёмке — `pending acceptance`, раздел замечания — `Observation`.

### З1. Формат на английском

- Скриптом по разделу «формат»: константы формата (`checker/conventions.py`
  и потребители), тесты, фикстуры и эталоны графа, рабочие документы самого
  lipi (меняются шапки и обязательные заголовки, текст остаётся).
- Коды в JSON — английские значения.
- Тем же шагом — все примеры, которые тесты сверяют с фикстурами,
  включая примеры в русском описании.
- По ходу — только адресные тесты разбора, рабочих документов и JSON.

**Готово (контрольная точка 1):** полный набор тестов; `lipi check` и
`lipi audit` — 0/0; в шапках рабочих документов lipi нет русских служебных
строк.

2026-11-19: З1 выполнена. Полный локальный прогон — 1079 тестов, все прошли.
У 23 рабочих документов сверены поля, даты и сохранность значений со старым деревом.
На временном проекте проверены создание документов, сборка указателя и срез решения.
После обновления описания отдельно проверены 33 пары A4: для 31 записаны
отметки с объяснениями, по двум уточнены условия восстановления `Closed` при
переносе по годам. Проверка и аудит дали 0 ошибок и 0 предупреждений.

### З2. Интерфейс

- Каждому языку соответствует папка `src/lipi/locale/<язык>/`:
  каталог `messages.json`, словарь `terms.json` и комплект `templates/`.
- Английская папка задаёт исходные сообщения, термины с короткими
  определениями и шаблоны. Правила в `.agents/lipi/` и шаблон CI берутся только из английской папки. Русская содержит переводы сообщений, терминов и заготовок `seed/`.
  Переводы всех трёх частей хранят отпечатки английских исходников.
- Наличие папки делает язык доступным в `lipi lang`. Выбор хранится в
  личном конфиге. Для отсутствующего ключа или шаблона используется
  английский. Отчёт перечисляет пропуски и устаревшие переводы по всем трём частям.
- Рабочая таблица З1 удаляется, тесты формата используют константы кода.
- По ходу — на каждой порции сообщений проверяются затронутые команды.

**Готово (контрольная точка 2):** полный набор на английском и русском
после объединения работы; один и тот же проект на двух языках — текст
меняется, машинные значения JSON совпадают; при смене языка правила, файл CI и lock побайтно совпадают, заготовки сохраняют первоначальный язык; без конфига — английский;
`lipi lang ru` — русский; удалённый ключ из русского каталога — английский текст и
строка в отчёте; изменённый английский исходник — строка «устарело».

2026-11-19: контрольная точка З2 пройдена. По 1085 тестов прошли с английским
и русским личным профилем. На одном проекте с русскими данными текст D1
меняется, а сериализованный JSON и коды возврата совпадают для шести вызовов
`check --structure`, `audit`, `map`, двух запросов `slice` и отказа `review`.
У русского перевода 891 сообщение, 48 терминов и 11 шаблонов.
Отчёт по всем трём частям пуст; проверены и пропуски, и смена отпечатков
на отдельном неполном языке. В локальном wheel есть все 27 файлов языков.
Перед коммитом `lipi check` дал 0/0, в аудите — 166 предупреждений A4 после
изменения размеченных областей кода и тестов. Пары требуют сверки с описанием
в З3. Новых отметок просмотра в З2 нет.

### З3. Описание

- Переводчик берёт термины из `locale/en/terms.json` и `locale/ru/terms.json`.
- Английская редакция готовится сразу после согласования словаря,
  параллельно З1–З2, отдельно от рабочего дерева. Места с выводом CLI
  переводчик помечает в черновике и после З2 сверяет с реальным выводом
  команд за один проход; текст сообщений сам не переводит.
- `lipi mv docs docs/ru` — одной командой; `docs/en/` — с теми же якорями;
  ключ `languages`, основная редакция `en`.
- Корневые `README.md`, `SETUP.md` — английские, со ссылками на обе
  редакции; пакет поставляет обе. Корневой `AGENTS.md` на английском ссылается на собственные правила разработки lipi на [английском](../../../.agents/README.md) и [русском](../../../.agents/ru/README.md). Управляемые правила самого lipi развёрнуты на английском.

**Готово:** обе редакции, якоря и ссылки в пакете проверены, L1–L3 и
`lipi check` чисты. По принятому уточнению A4 на истории З2–З3 проверяются
выборкой с расширением по модулю при расхождении. На снимке с одним коммитом
проверка и аудит должны дать 0/0. При правке кода — адресные тесты.

2026-11-19: З3 выполнена. Описание перенесено командой `lipi mv docs docs/ru`.
В пакете обе обязательные редакции: 15 пар страниц, по 125 явных якорей;
основная — `en`. Проверены относительные ссылки, логотип и вывод `lipi guide`
из установленного wheel.

На `9118672` воспроизведены 166 A4. Независимая выборка — 20 пар из 17
файлов (seed 20261119, повышен вес изменений логики). После расширения
проверены 79 пар из 25 файлов, ещё 87 остались только в описи. Исправлены
или уточнены 12 разделов обеих редакций: язык указателей, шаблонов, текстового
и машинного вывода, а также условия D1 и L1. Новые отметки не ставились.
Перед коммитом в рабочей истории аудит дал 0 ошибок и 140 A4. На отдельной
копии состава с одним начальным коммитом `check` и `audit` дали 0/0.

При вычитке З4 уточнены З2 и З3. Правила и CI разворачиваются из
английской редакции у всех пользователей. Русский каталог содержит 889
сообщений, 48 терминов и 6 проектных заготовок. Проверены первая установка
на каждом языке, повторный `init` после смены языка и обновление старого
русского развёртывания. Управляемые файлы и lock совпадают побайтно,
заготовки сохраняются. В репозитории lipi корневой `AGENTS.md` ведёт
на собственные правила разработки в двух редакциях. Полный локальный набор
прошёл на английском и русском (по 1087 тестов). В чистой установке
локального wheel прошли 6 проверок пакета.

### З4. Первый выпуск заново

- Просмотр английских текстов пользователем: каталог, шаблоны, описание.
- История сводится в один коммит; `CHANGELOG.md` — одна запись
  «1.0.0 — первый выпуск»; теги `v1.0.0` и `v1` — на этот коммит.
- Чистая установка из GitHub: `lipi init`, `check`, `slice`, `lang`.

**Готово (контрольная точка 3):** чистая установка из опубликованного
тега; выпущен `lipi 1.0.0`; публикация — по поручению пользователя.

## Порядок <a id="order"></a>

З0 → З1 → З2 → З4; З3 — перевод после З0 параллельно, сверка вывода после
