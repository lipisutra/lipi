# Описание lipi

Начало работы — [установка и развёртывание](../../README.md#install);
исполнителю перед `lipi init` — [SETUP.md](../../SETUP.md).
Здесь собраны правила и справочники для работы с настроенным проектом.

Чтобы получить русские заготовки проекта, выполните `lipi lang ru` перед
первым `lipi init`. См. [язык интерфейса](settings.md#interface-language).

[English edition](../en/README.md).
