# lipi documentation

Start with [installation and setup](../../README.md#install). Agents should
read [SETUP.md](../../SETUP.md) before running `lipi init`. These pages
cover the rules and commands for an initialized project.

For Russian starter files, run `lipi lang ru` before the first `lipi init`.
See [interface language](settings.md#interface-language).

Read this documentation [in Russian](../ru/README.md).
