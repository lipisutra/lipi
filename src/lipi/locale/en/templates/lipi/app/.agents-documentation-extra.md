
## User help and system documentation <a id="help"></a>

User help in `{{DOCS}}/` is for people using the app. System documentation
in `{{DESCRIPTION}}/` is for developers and owns the rules.

- Keep code paths out of system documentation where possible so it makes
  sense to readers who never open the code. Use `@trace` to link from code.
- A user help page identifies the system documentation sections it
  explains. Use a path from the project root and an explicit anchor:

```
<!-- covers: {{DESCRIPTION}}/README.md#processes, {{DESCRIPTION}}/README.md#rules -->
```

- When a section of system documentation changes, `lipi check --staged`
  and `lipi check --diff` flag user help pages that name it in `covers`
  for review (T2), unless the help page itself is part of the change.
- Every system documentation page must be reachable from
  `{{DESCRIPTION}}/README.md`. A link from user help does not count.
